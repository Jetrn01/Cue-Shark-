# PottersMate V17 — Tournament Command Centre

Built on V16.

Tournament Control is now designed as the organiser's primary night-of-event screen:
- At-a-glance live summary of playing, ready, waiting, available and completed matches.
- Table cards show the current match, score, race and scoring link.
- Available tables can assign the next eligible match with one click.
- A prominent Next Up panel shows the next three ready matches and provides one-click table assignment.
- Accessibility-required matches remain prioritised and only receive suitable tables.
- Existing detailed Ready to Play, Waiting and Latest Results sections remain available below.
- Automatic refresh and existing QR/scoring workflow are retained.
- No SQL/database changes required.
