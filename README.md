# Cue Shark

Initial Next.js + Supabase starter for Cue Shark.

## Supabase
The database schema should already be created in the Supabase project.

## Environment variables
Create a `.env.local` file using `.env.example` and add your Supabase Project URL and Publishable Key.

Do not add `.env.local` to GitHub.

## Next step
Deploy this project through Vercel, then add the same environment variables in Vercel.
