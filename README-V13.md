# PottersMate V13 — Organiser Polish

This version focuses on tournament-day clarity and protecting the draw once play has begun.

Changes:
- Adds a compact tournament status strip to the competition header.
- Draw settings lock once a match is completed or in progress.
- Scheduled draws can still be intentionally regenerated before play starts.
- Draw modal warns when an existing scheduled draw will be replaced.
- Regenerate/Generate button text reflects whether a draw already exists.
- Reverse Crossover one-time protection from V12.6 is retained.
- No database or SQL changes required.
